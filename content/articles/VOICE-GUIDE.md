## ผู้อ่าน

เจ้าของโรงงาน วิศวกรโยธา วิศวกรควบคุมงาน ผู้รับเหมาก่อสร้าง และฝ่ายจัดซื้อ
ที่กำลังหาข้อมูลเพื่อตัดสินใจซื้อ ยื่นงาน หรือตรวจรับงาน ทุกคนอ่านออกว่า
DFT, Hp/A, BOQ, TDS, วุฒิวิศวกร คืออะไร ไม่ต้องอธิบายซ้ำ

## กฎ 10 ข้อ

1. **น้ำเสียง** วิศวกรอาวุโสอธิบายให้เพื่อนร่วมวิชาชีพฟัง สุภาพ ตรง ไม่ตื่นเต้น
   ไม่ขาย ไม่ใช้คำอุทานหรือคำพูดปาก
2. **ไม่เรียกผู้อ่านว่า "คุณ"** ใช้ประธานเป็นงาน โครงการ ผู้รับเหมา เจ้าของโครงการ
   หรือละประธาน เช่น "โครงการที่ต้องยื่นขออนุญาตควรเตรียม…"
3. **ใช้ศัพท์วิชาชีพตรง ๆ** นิยามครั้งแรกแบบสั้นในรูป "X คือ…" แล้วไม่ต้องอธิบายอีก
4. **ทุกย่อหน้ามีตัวเลข ชื่อมาตรฐาน หรือข้อเท็จจริงจากงานจริงอย่างน้อยหนึ่งอย่าง**
   ย่อหน้าที่ไม่มีให้ตัดทิ้ง ตัวเลขทุกตัวต้องมีที่มาจากข้อมูลสินค้าหรือผลทดสอบจริง
5. **ประโยคสลับสั้นยาว** ย่อหน้าละ 2 ถึง 4 ประโยค ห้ามปิดย่อหน้าด้วยประโยคสรุปซ้ำ
6. **ห้าม em dash (ขีดยาว U+2014) และ en dash (ขีดกลาง U+2013) ในเนื้อความ ห้าม `--`** ใช้จุด คำเชื่อม
   หรือวงเล็บแทน คง en dash ไว้เฉพาะช่วงตัวเลข เช่น 23–25 ตร.ม.
7. **ห้ามสำนวนในตารางด้านล่าง** ห้าม "ไม่ใช่ X แต่เป็น Y" ห้ามยกของสามอย่างเสมอ
   เว้นแต่ของจริงมีสามอย่าง
8. **หัวข้อเป็นประโยคบอกเล่า** ไม่ใช่คำถาม ยกเว้นในส่วนคำถามที่พบบ่อย
9. **เปิดบทด้วยคำตอบใน 40 ถึง 60 คำแรก** ปิดบทด้วยสิ่งที่ผู้อ่านต้องทำต่อ
   ไม่มีย่อหน้าสรุปที่ทวนเนื้อหา
10. **byline เป็นชื่อวิศวกรจริงพร้อมเลขทะเบียน** (รอข้อมูลจากลูกค้า)

## สำนวนที่ห้ามใช้

| ห้าม | ใช้แทน |
|---|---|
| ในโลกปัจจุบัน / ในยุคที่… | ตัดทิ้ง เริ่มที่ข้อเท็จจริงเลย |
| สิ่งที่ควรทราบคือ / ที่น่าสังเกตคือ / เป็นที่น่าสนใจว่า | ตัดทิ้ง พูดเนื้อหาเลย |
| ไม่เพียงแต่…แต่ยัง… | แยกเป็นสองประโยค |
| นอกจากนี้ / ยิ่งไปกว่านั้น / ท้ายที่สุด (ขึ้นต้นย่อหน้า) | ตัดทิ้ง หรือใช้ "อีกกรณีหนึ่ง" เมื่อจำเป็นจริง |
| สรุปได้ว่า / กล่าวโดยสรุป / โดยสรุปแล้ว | ตัดทิ้ง |
| ใช้ประโยชน์จาก / ปลดล็อก / ยกระดับ / ตอบโจทย์ | ใช้ / ทำให้ / ลด / เพิ่ม |
| ครบวงจร / ล้ำสมัย / ไร้รอยต่อ / มืออาชีพ (คำโฆษณา) | ระบุสิ่งที่ทำได้จริงเป็นตัวเลข |
| มาดูกัน / มาทำความเข้าใจกัน / ลองมาดู | ตัดทิ้ง |
| เมื่อพูดถึง… / ในเรื่องของ… | ตัดทิ้ง |
| ทำหน้าที่เป็น / ถือเป็น / นับเป็น | คือ / เป็น |
| ทีนี้ / เป๊ะ / จับโป๊ะ / ง่าย ๆ คือ / พูดอีกแบบคือ / จะเห็นว่า | ตัดทิ้ง หรือเขียนใหม่เป็นภาษาเขียน |
| ผู้เชี่ยวชาญกล่าวว่า / มีรายงานว่า (ไม่ระบุแหล่ง) | ระบุชื่อสถาบัน ปี และเลขรายงาน |

## โครงสร้างที่ AI ชอบทำ ห้ามทำ

- ยกของมาสามอย่างเสมอ (rule of three)
- หัวข้อเป็นคำถามซ้ำ ๆ ทั้งบท
- ทุกย่อหน้าจบด้วยประโยคสรุปหนึ่งประโยค
- ประโยคยาวเท่ากันหมดทั้งย่อหน้า
- เปิดบทด้วยฉากทั่วไป ("คำถามที่ได้ยินบ่อยที่สุดคือ…")
- ตัวหนาพร่ำเพรื่อ ขีดคั่นระหว่างหัวข้อ
- คำถามเชิงวาทศิลป์ปิดย่อหน้า
- ย่อหน้าสรุปท้ายบทที่ไม่มีข้อมูลใหม่
